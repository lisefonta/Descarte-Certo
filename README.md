# Descarte Certo ♻️

Projeto acadêmico de educação ambiental e sustentabilidade.

## Como abrir no VS Code (Windows)

1. Extraia o arquivo `Descarte_Certo_Projeto.zip`.
2. Abra o **Visual Studio Code**.
3. Vá a **Arquivo > Abrir Pasta** e escolha a pasta `Descarte_Certo`.
4. Clique duas vezes no arquivo `index.html` no explorador do VS Code.
5. Para visualizar o site, clique com o botão direito no arquivo `index.html` e escolha **Reveal in File Explorer / Revelar no Explorador de Arquivos**; depois abra o arquivo no Chrome ou Edge. Você também pode instalar a extensão **Live Server** e usar **Open with Live Server**, mas não é obrigatório.
6. Teste os filtros, a busca e o quiz. Redimensione a janela para conferir o layout responsivo.

**Não precisa instalar Python, Node.js, pacotes ou banco de dados.** Basta abrir o HTML no navegador.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `style.css`: cores, organização e responsividade.
- `script.js`: dados do guia, filtros, busca e quiz.
- `DOCUMENTACAO.md`: relatório técnico, requisitos, protótipo textual, testes e melhorias.

## Como personalizar

- Para mudar o nome do projeto, altere o texto em `index.html`.
- Para adicionar materiais, edite a lista `materiais` em `script.js`.
- Para mudar cores, edite as variáveis no início de `style.css`.

## Entrega sugerida

Confira as exigências específicas do professor. Se for solicitado o código, envie a pasta compactada. Se for solicitada apresentação, faça uma demonstração do guia, filtros, busca, quiz e layout no celular.

## Observação

O conteúdo é educativo e geral; o descarte correto pode variar por município e operador de coleta. O projeto não consulta pontos de coleta reais.
